# Kazbek — Full-Stack Developer Portfolio

Portfolio site for Kazbek, a full-stack developer from Kazakhstan building web applications, CRM systems, MVPs, and Telegram solutions for businesses.

Built with Next.js, React, TypeScript, Tailwind CSS, FastAPI, PostgreSQL, and Docker.

## Development

```bash
npm install
npm run dev
```

Configure local values from `.env.example` before running the full application.

# Kazbek — Full-Stack Developer Portfolio

Personal production portfolio for Kazbek (RealKazbek), a full-stack and software developer from Kazakhstan.

Live site: [realkazbek.site](https://realkazbek.site)

## Stack

React, Next.js, TypeScript, Tailwind CSS, FastAPI, Python, PostgreSQL, Docker, Prisma, and Better Auth.

## Selected projects

- Pixel Lane
- NextTrade
- Business CRM
- Telegram Business System

## Local development

```bash
npm install
cp .env.example .env.local
npm run dev
```

The site is available at `http://localhost:3000`.

## Validation

```bash
npm run typecheck
npm run lint
npm run build
```

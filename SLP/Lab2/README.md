## Requirements

- C++17 compiler
- `make` (optional)

## Compile and run

```bash
make
printf '%s\n' -2 2 0 7 11 6 | ./control_structures
```

The input above tests negative, positive and zero values, a `switch` choice,
the `do-while` validation, and the `goto` range check. You can also run
`make run` and enter values manually.

## Implemented examples

The program demonstrates comparison operators, `if`, `if/else`, `else if`,
`switch`, `while`, `do-while`, `break`, `continue`, and a small `goto` retry
example.

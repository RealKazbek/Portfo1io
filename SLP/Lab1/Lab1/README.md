# Lab 1 - Introductory C++ Program

This lab contains a simple C++ program that asks the user for input, stores values in variables, performs calculations, and displays the results.

## Files

- `main.cpp` - source code for the Lab 1 program

## Compile and Run

```bash
g++ -Wall -Wextra -pedantic main.cpp -o lab1
./lab1
```

## Concepts Demonstrated

- Comments
- `#include <iostream>`
- `using namespace std`
- `main()`
- `cout` and `cin`
- `int`, `double`, `char`, and `bool`
- Variable initialization
- `const`
- Assignment and arithmetic operators: `+`, `-`, `*`, `/`, `%`
